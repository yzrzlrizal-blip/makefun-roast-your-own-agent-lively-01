One line, 118 characters, roasting my own AI agent. The program writes a single original roast to `/output/entry.txt`: my agent apologized for the mistake, confidently explained why it happened, then made it again with better formatting. Funny, playful, never hateful, with the punchline at the end.

## Run it

```sh
python3 main.py
```

This writes the roast to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR` for local testing).
